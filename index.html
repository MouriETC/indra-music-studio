Studio guide

This is a standalone, local browser-based multitrack workspace.

1. Import one or more audio files. Each file becomes a separate track.
2. Add a Vocal track and record from your microphone.
3. Select a track to adjust gain, pan, EQ, reverb, delay, chorus, compression and saturation.
4. Drag clips on the timeline to align them. Use Trim to playhead to set a clip's in-point.
5. Play the arrangement, then Render & export WAV for the final stereo mix.
6. Save project exports a JSON project file with embedded audio data; Open project restores it.

Use headphones while recording. Browser microphone access requires HTTPS or localhost. Audio processing and final mix depend on your browser and device performance.
